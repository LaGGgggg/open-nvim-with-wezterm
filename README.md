### Open [Neovim](https://neovim.io/) with [WezTerm](https://wezterm.org/) via Windows Explorer context menus
This project provides a small Windows registry file to open Neovim in WezTerm terminal via
Windows Explorer context menus.
The project tested on Windows 11.

### How to use
1. Clone this repository: `git clone https://github.com/LaGGgggg/open-nvim-with-wezterm.git`
2. Open [open_with_nvim_with_wezterm.reg](open_with_nvim_with_wezterm.reg) file in a text editor and
    change all paths to your own:
    `C:\\Users\\User\\Desktop\\open-nvim-with-wezterm\\` -> your path to the cloned repository directory.
    `C:\\Program Files\\WezTerm\\wezterm-gui.exe` -> your path to the WezTerm executable file if it's different.
> [!WARNING]
> **Please double-check this file before run it! Understand all changes it will apply. Manual registry edit can be dangerous!**
3. Save the file and double-click it to apply changes to the Windows registry.
